# ScreenTranslator

An Android app project for on-screen OCR translation and real-time subtitle experiments.

## Planned features

- Screen capture with Android MediaProjection
- On-screen text recognition (OCR)
- Configurable translation API endpoint and model settings
- Floating translated text overlay
- Optional speech transcription and translated subtitles

## Status

Early starter project. Features listed above are planned and are not yet implemented unless present in source code.
